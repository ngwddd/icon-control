# Third-party code

The compatibility package name `computer_mcp` is retained. The `actions/`, core
utility modules, CLI and package entry points originate from computer-mcp 0.0.7
(MIT), copied from the existing installed baseline to make this repository
self-contained rather than relying on edits to another distribution's files.
The Icon Control patch layer and execution guards are maintained in this repository.
Retained upstream module docstrings and the repository MIT license apply.
Runtime dependencies retain their own licenses and are declared in pyproject.toml.
