# 一键授权候选代码交付

集成代码在 codex/rc2-d-verification，PR #5。前置 PR 顺序为 #2、#3、#4、#5。

首次通过 DSH 原按钮打开原生胶囊，在“绑定目标与高级设置”中选择 Agent 和一个应用，点击“保存常用目标”。之后原生胶囊的一次点击授予屏幕读取、鼠标和文字输入。多个会话时使用保存的明确选择，唯一会话可自动识别。进程启动时间或路径改变需要重新绑定。关闭胶囊、撤销和急停后需新的用户授权。

高级设置包含文件读取、写入、删除、运行配置、关闭窗口和固定程序启动。外部文件通过“批准单个文件读取”选择，限 1 MiB。文件变化后需重新批准。普通宏读取只允许宏目录中的有界文件，未知宏动作拒绝执行。

旧训练记录缺少 owner 时被隔离。用户可在安装环境执行 tools/migrate_legacy_dataset.py --source 旧JSONL --agent 完整活跃会话ID --confirm-migration，将指定记录脱敏后追加到该会话。输入限 16 MiB，重复运行会再次导入。建议逐份迁移并保留原始备份。

代码检查覆盖当前修改的回归和构建。用户负责原生单击、撤销、窗口焦点切换、32 项真机任务、物理接管和急停以及干净 Windows 账号验收。验收要求见 DESKTOP-BENCHMARKS.md。版本继续为 1.3.0rc2，发布闸门仍绑定对应源码 SHA。

回滚按 PR 依赖的逆序撤销。新 file_read 授权通过原生高级设置批准，旧 DSH 插件入口继续打开原生窗口。
