# Icon Control v1.3 稳定性重构计划

基线：v1.2.0，提交 98b38b4。升级分支：codex/v1.3-stability。
依据用户提供的六阶段任务书；共享聊天链接暂时不可读取，未取得额外附件。
目标版本 v1.3.0；未满足验收门槛只能交付候选版，不打正式发布标签。

| 阶段 | 范围 | 验收 |
|---|---|---|
| S0 | 锁定源码、工具清单、测试范围、回滚点 | 基线记录可复查；不把历史通过数当本轮结果 |
| S1 | Token、执行点权限、接管、双 ESC | 缺 Token、伪造状态、撤销、接管、急停均拒绝后续动作 |
| S2 | 能力声明、统一内核、任务状态与验证 | 内外调用遵循相同策略；branch/photo 无假成功 |
| S3 | 窗口绑定快照、引用失效、混合定位 | 过期、变窗、重复目标不得误点 |
| S4 | 完整打包、认证传输、安装回滚、CI | 干净环境安装并可回滚；旧接口有迁移说明 |
| S5 | 至少 30 个桌面任务、性能与风险复核 | 分清模拟测试与真机证据；不通过不正式发布 |

每阶段独立提交。各提交及文件可用 git show 复查；撤回单阶段使用 git revert 对应提交。
隔离源码、测试环境与已安装宿主；验证不得修改用户真实授权或模拟人类点击授权。
先审查 S1 的缺陷与修复证据，再推进后续能力；工程测试不自动证明真机接管可靠。
