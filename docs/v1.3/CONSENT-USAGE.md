# 授权怎么用（v1.3.2）

## 一次性设置

不需要。装好后宿主进程会常驻，托盘有图标、热键已注册。

## 日常

### 打开授权窗口

两种方式，效果一样：

1. **热键 `Ctrl+Alt+Shift+F9`**（被别的软件占用时会自动退到 F7 / F12 / G）；
2. **点托盘图标**（Win11 默认收在「隐藏的图标」里，可以在任务栏设置里固定出来）。

### 窗口里怎么选

```
Agent:  DeepSeek Harness · 4f21f3328        ← 谁在申请
目标:   EXCEL.EXE · PID 1234                 ← 对哪个应用（打开窗口时的前台应用）
◉ 常用：读取整个桌面 + 鼠标键盘 + 文字输入
○ 只读：只读取整个桌面与窗口信息
○ 全部：再加剪贴板读写、文件读写、启动/关闭程序
☑ 60 分钟内，本工作区的新进程自动沿用这次授权
[ 一键授权 ]  [ 取消 ]
```

- **回车 = 一键授权**（默认选中「常用」和 60 分钟）。
- 目标不对？先关掉窗口，把要操作的应用切到前台，再按热键重开。
- 「常用」不含剪贴板和文件权限；要跑需要这些的操作，选「全部」。

### 60 分钟租约

- 从点「一键授权」开始算 60 分钟。
- 这期间**同一工作区**（同一个项目目录）新起的 MCP 进程自动继承，**不再弹窗**。
- 换一个工作区（另一个项目目录）会重新问 —— 这是有意的边界。
- 到期前没有提醒；到期后下一次调用才弹窗。

### 查看 / 续期 / 撤销 / 退出

已授权时再按一次热键（或点托盘），窗口会变成：

```
[ 续 60 分钟 ]  [ 立即撤销 ]  [ 退出 Icon Control ]  [ 关闭 ]
```

- **续 60 分钟**：从当前时刻重新算 60 分钟。
- **立即撤销**：1 秒内全网失效，在途调用也会被拒（fail-closed）。
- **退出 Icon Control**：撤销并关掉托盘/热键宿主。

## 出问题时

| 现象 | 原因 / 处理 |
|---|---|
| 按热键没反应 | 热键被占用。看 `%LOCALAPPDATA%\IconControl\state\consent-host.json` 里的 `hotkey` 字段，那是实际绑定的组合 |
| 托盘里找不到图标 | Win11 把新图标默认放进「隐藏的图标」，任务栏设置 → 其他系统托盘图标 → 打开「Icon Control」 |
| 窗口弹出来但在别的窗口后面 | 点一下窗口标题栏即可。没有真实按键/点击时 Windows 不给前台权限 |
| 窗口里 Agent 显示的不是你要的那个 | 它取的是**最新注册的活会话**；先让目标宿主发起一次操作，再按热键 |
| 提示「没有活跃的 Agent 会话」 | 宿主还没连上；先在 DSH 里随便调一次桌面工具，再按热键 |
| 提示「找不到前台应用」 | 先把目标应用切到前台，再按热键 |

## 安全边界（没有变松）

- 授权只能由**人**在窗口里点 / 托盘点 / 热键唤出后回车触发，agent 调不到这些入口。
- 撤销即时生效；宿主进程退出等于撤销。
- 60 分钟到期自动失效。
- 租约只覆盖**同一个工作区 + 同一批被批准的应用**；换工作区、换应用都要重新确认。
- 每次执行仍做目标校验（前台窗口、控件归属、目标进程仍在批准列表）。

## 命令行（排障用）

```powershell
# 打开授权窗口
python -m computer_mcp.consent

# 看宿主到底绑了什么
Get-Content %LOCALAPPDATA%\IconControl\state\consent-host.json

# 紧急撤销（任何人可降级）
python -c "from computer_mcp import consent_ipc; consent_ipc.request('emergency')"

# 旧控制中心（逐项勾选，仅内部调试）
python -m computer_mcp.consent --tk
```
