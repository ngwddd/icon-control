# v1.3 RC2 安全协议迁移

保留 89 个 MCP 工具名称和旧别名。以下是有意收紧的安全语义；旧脚本不能依赖旧的全局鼠标开关。

- 授权改到原生控制中心，由人选择一个 Agent 会话、能力和具体应用进程。stdio 每个进程独立；HTTP 客户端应使用各自凭据。重启客户端、切换会话或重启授权桥都需要重新授权。
- DSH 胶囊只读取后端确认状态并打开原生控制中心，不再持有长期密钥，也不能发出授权或续期请求。“单会话已授权”不代表所有 MCP 客户端均有权限。
- 原生界面通过当前用户专用命名管道通信。桥自行启动隔离模式的界面实例，并核对进程归属及短期实例凭据；只模仿模块名称不能授权。
- 屏幕读取、物理输入状态观察、鼠标输入、文本输入、关窗、文件写入、删除、配置和启动程序分开批准。屏幕授权包括截图、OCR 和 UI 树；被拒响应不会偷偷附图。
- 允许的应用绑定 PID、进程启动时间和可执行文件。启动某个程序不自动批准其他实例；新进程要在控制中心刷新后单独选入输入范围。
- 续期不能增加权限。否定心跳、撤销、租约到期或急停会取消旧代际；恢复连接后的肯定心跳不能使旧任务恢复。
- 真人鼠标持续移动满 1 秒才接管；停顿超过 350ms 重新计时，多次短挪不累加。键盘、点击、滚轮、撤销和双 ESC 仍立即生效。
- ToolSpec.effects 和参数效果声明控制实际执行。vision_list 的 delete 需要删除权限，reset_stats 需要配置权限；查询不需要这两项写权限。
- verify_flow 报告只新建到安装目录下 workspace/reports；绝对外部路径、路径穿越、重解析点和覆盖已有报告均拒绝。dataset_export 的 tag 只能是一个名称。需要放到个人目录时由用户复制成品。
- 空验证、空任务、未知成功标志、独立的无关 assert、超时后继续，均不能证明先前动作完成。动作自己的 expect 才能验证该动作；track 依据实际逐步结果判定 verified。
- run_script 无应用后置验证时仍返回 executed_unverified；启动任务、动作已发出和目标状态已验证分别报告。
- 训练采集默认关闭。启用后，输入内容、敏感参数及异常原文不会保留；旧记录在读取、导出时也重新脱敏。保留的执行轨迹按 Agent 隔离并脱敏。
- 临时清理只扫描专用目录；进程外急停只结束登记且身份仍匹配的助手工作进程。安装切换及回滚先撤销旧许可。
- 删除无 Token 兼容、OCR 授权及 DSH_MOUSE_GATE=off 放行路径。读取不到有效许可、监听失败或授权服务不可用时拒绝执行。

原生控制中心需要 Windows CPython 的 Tk 运行库与 pythonw.exe，安装器会在切换环境前检查。正式发布必须另有完整真机证据；隔离回归不替代物理接管、双 ESC、DPI 或干净账号验收。
