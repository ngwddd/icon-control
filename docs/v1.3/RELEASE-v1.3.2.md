# Icon Control v1.3.2

授权体验重做：**一个原生窗口、一次点击、一小时租约**。这是 P0–P2 的第一批落地。

## 新增

- **原生授权窗口**（`comctl32!TaskDialogIndirect`，纯 ctypes，无 Tk、无 C#）：
  三档预设「常用 / 只读 / 全部」+「60 分钟内本工作区自动沿用」+ 一键授权，**回车即批准**。
- **身份级租约**：授权主体 = 安装目录 + 工作区派生的 `agent_id`，60 分钟内同一工作区的新进程自动继承，重启 MCP 不再重授。
- **托盘常驻**：显示剩余时间，右键「打开授权窗口 / 立即撤销 / 退出」。
- **全局热键** `Ctrl+Alt+Shift+F9`，被占用时自动退到 F7 / F12 / G；实际绑定写在 `state/consent-host.json`。
- **已授权时按热键**显示当前租约，可「续 60 分钟」或「立即撤销」。

## 修复

- **授权即交接**：授权时间晚于最后一次物理输入时，控制权直接交给 AI，不再出现 `控制权在用户手上（0.0s 前）`（验收里两次假失败的根因）。
- 撤销立即生效，心跳进程自动退出。

## 移除

- DSH 胶囊：`plugin/client.js` 不再渲染按钮；`quick_grant.py` 与 `quick_bind / quick_preview / quick_grant` 三条 IPC 删除；授权窗口不再有「高级…」入口。

## 验证

- 回归：542 项运行 / 0 失败 / 0 错误 / 3 跳过（新增 13 项租约、交接与宿主分发用例）。
- 真机：窗口渲染 ✓、回车授权 ✓、新进程继承租约 ✓、跨工作区不继承 ✓、紧急撤销立即失效 ✓、托盘图标注册 ✓、热键注册并回退 ✓。

## 已知问题

- 本机 `Ctrl+Alt+Shift+F9` 已被其它程序占用，实际绑定为 `F12`。
- 托盘图标在 Windows 11 下默认收进「隐藏的图标」区，需要在任务栏设置里勾出来。
- 合成按键（SendInput）不会触发全局热键，需要真实按键；热键消息处理路径已用 `WM_HOTKEY` 注入验证。
