# v1.3.7 真机反馈代码整改交接

本分支基于正式版 6850ebe，保留原 89 工具并新增 scroll。代码仍处于开发分支，未替换正式包、未操作或关闭微信。

## 交付

1. runtime_contract 在当前 MCP 工具响应与 control_status 中显示版本及工具定义 SHA-256；完整诊断提供 click 的实际 inputSchema。客户端缓存不一致时要求重连并重新 tools/list，不能强制宿主丢弃缓存。
2. setup.py 构建钩子给 wheel/sdist 写入源码 SHA 与 dirty 状态，不生成验收结果；旧安装无构建元数据时明确报告来源不可用。
3. 原生应用选择没有隐式首选项，单候选也须用户明确选择；可信待请求目标仍被锁定。
4. type 返回 text_integrity 与下一步逐字核对指引，不推断应用已收到原文。摘要不能定位宿主上游是否丢字符，也不能替代草稿读取。
5. scroll dy 正向上、负向下，dx 正向右；单轴整数幅度 [-100,100]，禁止零向量；支持成对 x/y，注入前检查位置及目标进程。
6. guarded_click 要求非空 before/after 视觉条件，只点击一次，失败停止，不能通过 retry 参数重复点击；微信宏必须提供 target_hwnd、当前界面判据 main_query 和 moments_content_query；缺参或空值在动作前拒绝。
7. 微信宏坐标是历史候选，不保证适用所有版本/DPI；没有合适视觉证据时停止。并未替用户发消息或建立无需确认的发送路径。
8. 用户原有或要求保留的应用不在任务收尾时自动关闭；同工作区的新会话不会继承授权。

## 验证归属

本轮按用户要求未运行测试、构建、CI 核查或真机验证。新增测试均为未执行代码。32 项任务与独立验收资料仍由用户提供，未复制旧 SHA 验收结论。

- 安装与 MCP 协议代码统一读取包内 tool_manifest.json，比较实际工具名称/定义，不再散落固定工具数。
