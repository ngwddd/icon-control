# Icon Control v1.3.4

授权从"用户找入口"变成"窗口来找用户"。

## 新增

- **被拒即弹窗**：工具因为缺少授权或权限范围不足被拦下时，`permission.check_tool` 会请求打开授权窗口，窗口自己出现，不用用户去翻托盘或记热键。20 秒内最多弹一次，可用 `ICON_CONTROL_AUTO_CONSENT=0` 关闭。
- **窗口认得出是谁在申请**：拦截方把自己的会话 id 一起带过去，窗口优先显示**发起调用的那个 Agent**，而不是"最后注册的那个"。
- **目标应用兜底**：前台窗口如果是授权窗口自己，就沿窗口链找第一个不像 Icon Control 的可见窗口，不再动不动"找不到前台应用"。
- **提示框**：「没有活跃的 Agent」「找不到前台应用」改成单独的说明框，不再占用 Agent/目标字段。

## 修复

- 未授权错误文案改为可操作提示（按 `Ctrl+Alt+Shift+F9` 或点托盘），不再指向已删除的旧开关。

## 验证

- 回归：**546 项运行 / 0 失败 / 0 错误 / 3 跳过**（新增 2 项自动弹窗用例）。
- 真机：从终端触发一次被拒调用 → 窗口自动出现，Agent 显示调用方会话，目标显示前台应用。
