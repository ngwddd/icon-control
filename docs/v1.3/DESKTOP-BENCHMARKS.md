状态：以下 32 个任务尚未执行，不能计作通过。隔离单元测试和 SDK 握手不代替这些任务。
使用独立测试账号／本地编辑器或专用夹具窗口，不操作真实聊天、业务资料或用户已有文档。
执行前由用户在候选版界面点击授权；测试程序不得写真实 granted=true 或修改权限状态。
