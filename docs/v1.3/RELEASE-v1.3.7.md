# Icon Control v1.3.7

本版本经项目所有者明确批准，作为正式版发布。

## 主要修改

- 授权请求绑定真实调用者、工作区、目标进程和请求 ID；支持补授权及调用者状态诊断。
- 请求队列回收与去重、状态回查、授权操作回读和取消，减少失效请求和通信失败造成的状态错配。
- 异常通知在锁外显示，后台否定心跳可继续尝试发送。
- 正常按键释放复核目标，窗口键盘绑定进程身份；急停清理不会向复用句柄的其他进程发送按键释放。
- 复制、剪切和粘贴快捷键统一遵守剪贴板独立权限，覆盖字符键、数字 VK 及左右修饰键。
- 关闭请求与确认关闭分开报告；verify_flow 根据验证计划预先检查屏幕读取、文件读取及报告写入权限。
- Release 严格处理测试退出码，核对报告 SHA 和范围，并支持版本说明回退。

保留 89 个 MCP 工具及现有接口。升级后请重启 MCP、授权桥和原生授权宿主，并为实际请求会话重新授权。

## 发布说明

用户声明审计已结束并明确要求发布正式版。本次按用户指示进行版本更新、打包与发布，没有额外执行自动测试或 Windows 真机验证；没有将旧提交测试结果复制为本提交的验收证据。
