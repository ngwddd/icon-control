# Icon Control v1.3.7rc3

RC3 修复 RC2 第二轮审计的三项代码问题：

- 原生授权及撤销错误提示移到状态锁之外；错误窗口保持打开时，后台仍可尝试否定心跳。
- 20 秒请求缓存复用前通过 IPC 验证当前调用者及 pending/displayed 状态；消费、拒绝、过期、清理或不可查询的 ID 不再直接返回。
- Release 工作流增加发布说明回退并保留原有正式发布门禁。带 RC 标记的版本始终为预发布，不设为 latest。

保留 89 个 MCP 工具及现有 API。新增 request_status 仅为调用者范围内的只读 IPC，不授予或扩展权限。

升级后重启 MCP、授权桥和原生授权宿主，再重新授权。旧 RC2 标签保持不变。

本轮按用户要求未执行测试、检测、真机验收或独立复审。候选包交由用户验证，不代表正式稳定版验收通过；未沿用旧 SHA 的验收结果。
