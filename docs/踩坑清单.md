# 踩坑清单（24 条会导致"静默失败"的坑）

> 每一条都是真实发生过的。按"症状 → 根因 → 修法"排列。

## 前台与焦点

1. **点击落在别的窗口上** —— `SetForegroundWindow` 被 Windows 拒绝，目标没到前台。
   修法：`AttachThreadInput` 强攻 + **校验真的在前台**，不在就中止。
2. **窗口最小化时宏"成功"但什么都没点到** —— `GetWindowRect` 返回 -32000，坐标在屏幕外。
   修法：执行前自动 restore。
3. **在监控页/其他页面时读按钮亮度全是 0** —— 读的根本不是那个界面。
   修法：动作前先确认"在哪个页面"（用只在该页面存在的图案判定）。

## 坐标与区域

4. **窗口移动后旧坐标全废** —— 写死绝对坐标。
   修法：`GetWindowRect` → 相对坐标 → 绝对坐标，每次现算。
5. **视角/滚动变化导致按钮位置变** —— 按钮只在对应侧可见。
   修法：先平移/滚动到已知状态，再取坐标。
6. **PrintWindow 位图与客户区差一个边框** —— 裁剪后坐标全错。
   修法：整窗抓图后按绝对坐标过滤，不要先裁。
7. **点列表行时行位置已变** —— 下成了别的资源（本次：第一首歌 → 另一首歌）。
   修法：**点之前 OCR 核对行内容**，不能靠"我记得是第 N 行"。

## 状态与判定

8. **靠记忆判断开关状态** —— 灯/门/监控三套状态全失步过。
   修法：状态每轮从画面读，变量只当缓存。
9. **动画没走完就判状态** —— 反复开关同一个控件。
   修法：`sample_stable`（连采两次一致）或把稳定等待写进动作。
10. **租别人的模板** —— 阈值 0.62 在自己机器上 0 命中，闭眼守夜一整局。
    修法：模板必须自标定。
11. **判据随视角消失** —— 用"右按钮亮度"判断是否在监控页，视角一转就误判。
    修法：选只在该状态存在的特征（实测 1.000 vs 0.468）。
12. **假设了一个不成立的不变量** —— "四格归零后像素哈希相同"，实际四个槽位天生不同。
    修法：设计校验前先验证这个不变量在此系统成立；或改用单槽内自证（夹紧校验）。

## 输入与键盘

13. **有模态对话框时所有按键被吞** —— `***.exe <不存在的文件>` 会弹"要创建新文件吗"。
    修法：先查有没有对话框。
14. **`key:"enter"` 直接崩** —— pynput 不认字符串键名。
    修法：`resolve_key("enter")` → `Key.enter`。
15. **点"发送"按钮没反应** —— OCR 到的文字位置不准/按钮置灰。
    修法：用回车发送。
16. **逐字敲长文本又慢又容易错** —— 修法：剪贴板 + Ctrl+V。
17. **OCR 认不出小字/灰字** —— 修法：`upscale=3` + `boost`（ChatClient"发送" baseline found=0 → found=1）。

## 应用生命周期

18. **Electron 应用直接 Popen 静默秒退** —— 退出码 0、无窗口（VideoClient卡了 6 次）。
    修法：走 `explorer.exe <lnk>`（等同双击）。
19. **关窗 ≠ 退出** —— 托盘驻留，进程还在。
    修法：`exit_app` 显式结束。
20. **隐藏窗口（vis=0）用 ShowWindow 硬顶得到空白页** —— 修法：再跑一次 exe 触发单实例唤出。

## 补丁工程

21. **字符串替换打补丁静默失效** —— 片段不匹配时什么都不做，几小时后才发现"改了没生效"。
    修法：每次替换前 `assert 旧片段存在`，替换后 `ast.parse` 语法自检。
22. **同一个函数被定义两次** —— 后定义覆盖先定义，行为完全变了。
    修法：补丁后断言函数唯一。
23. **`_patched/` 与安装副本漂移** —— 备份是旧版，重装后回滚到旧行为（**v0.1 发布前刚抓到一次**）。
    修法：测试里加"字节一致"检查。

## 权限与安全

24. **agent 自己把授权开关点开** —— 等于绕过用户授权。
    修法：把开关做成 user-only（agent 只读，规则写死不许写 DOM / 改 localStorage / 用鼠标点它）。

---

## 一条通用判据

**"我以为成功了"永远不算证据。** 只认这几样：

```
· 剪贴板回读（Ctrl+A / Ctrl+C 后读）
· 文件是否生成、大小、内容
· 输入框是否被清空
· 消息气泡是否出现（OCR）
· 第三方日志（如 GamePlatform 创意工坊日志（***））
· screen_state 的 diff %
```
