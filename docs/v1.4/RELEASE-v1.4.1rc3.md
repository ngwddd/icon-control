# Icon Control v1.4.1-rc3

RC2 的引用完整性与目标解析修复版。**没有新增工具**（仍是 96 个）。

## 修了什么

| 编号 | 问题 | 修法 |
|---|---|---|
| C01 | 几何哈希被拿去比 AutomationId，有效引用被判 stale | 只比较真正的 AutomationId；融合过程保留该字段 |
| C02 | 窗口移动后引用仍带着旧点击中心 | 每次重定位都重算 cx/cy |
| C03 | 不传 hwnd 时找到了目标却没有 ref | 解析前台窗口并据此生成快照 |
| C04 | 引用失效被当成"元素已消失" | 失效后按名字复查，确认查不到才算消失 |
| C05 | 指定目标定位失败仍会打字 | 返回 `no_target`，不发送按键 |
| C06 | `execute_verified` 仍取第一个同名控件 | 四个工具共用 `_resolve_element()`，同名即 `ambiguous` |
| C07 | 混合快照 5 秒整体过期，连带清掉 120 秒引用 | 快照按最长引用保存，逐引用判 TTL |
| C08 | ScrollIntoView 成功后还补一次滚轮 | 只有 Pattern 失败时才滚轮 |

## 验证

- 回归 **848 项 / 0 失败 / 0 错误 / 3 跳过**
- 新增 10 项，逐条对应 C01–C08（AutomationId、中心坐标、无 hwnd 引用、混合快照寿命、
  引用失效不假成功、缺目标不打字、同名歧义、滚动不重复）
