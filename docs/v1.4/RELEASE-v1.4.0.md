# Icon Control v1.4.0

正式版。**授权系统移除，工具连接即用；急停、人机接管、目标窗口校验保留。**

## 核心变化

| 以前（1.3.x） | 现在（1.4.0） |
|---|---|
| 每次调用先证明"刚刚有人点过授权" | 连接即授权，工具直接执行 |
| 授权桥 + 托盘 + 热键 + 授权窗口 | 全部不再启动 |
| 升级/重启后重新授权 | 不需要 |
| 32 项人工授权验收基准 | 删除（授权流程已不存在） |

需要旧流程时：`ICON_CONTROL_POLICY=human`。

## 本轮修的问题

- `policy enable` 会顺手顶掉急停 → 只改模式
- 恢复与急停竞争可能吞掉新急停 → 不再删闩，检测到新急停即报错
- NaN/inf/未来时间被当作有效授权 → 一律拒绝
- `disable` 被环境变量覆盖却显示成功 → 返回码 3 + warning
- headless 下接管被时间戳夺回 → 该分支只对人工模式生效
- `exit_app` 模糊匹配 + 默认强杀 → 精确匹配、默认不强杀、终止前复核身份
- 隐私测试把随机会话 ID 误判成卡号 → 改为检查真正承载数据的字段

## 验证

- 回归 **773 项 / 0 失败 / 0 错误 / 3 跳过**
- 发布门禁：版本一致、回归绑定提交且全绿、stdio+HTTP 均 90 工具且版本一致、HTTP 无凭证 401
- 真机：微信发消息、朋友圈读取与转发、MCP stdio 全链路（无授权桥）

## 安全边界（必读）

免授权后，唯一的边界是 MCP 传输层：stdio 只对父进程可见，HTTP 必须 `127.0.0.1` + 客户端凭据。
急停（双 ESC / 看门狗）、人机接管、目标窗口身份校验、`executed_unverified` 语义均保留。
