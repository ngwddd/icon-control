# Icon Control v1.4.1-rc2

RC1 的修复版。**没有新增工具**（仍是 96 个），只把六个新工具的执行语义、引用身份和输入校验对齐。

## 修了什么

| 编号 | 问题 | 修法 |
|---|---|---|
| B01 | UIA 动作抛异常仍返回成功 | 动作不再吞异常，失败带原因；`SetValue` 改用正确方法并读回 |
| B02 | 融合定位丢 `path`，引用退化成 5 秒视觉引用 | 保留结构字段；混合结果按节点给 TTL |
| B03 | `wait_for(any)` 分发层漏传 | 补传 + 分发层回归测试 |
| B04 | `clear_first` 先输入后清理 | 改为聚焦 → 全选 → 删除 → 只输入一次 |
| B05 | `absent` 无引用时误判成功 | 无可观察引用时返回 `executed_unverified` |
| B06 | 按名定位丢窗口上下文 | 自动补前台窗口 |
| B07 | 同名控件默默取第一个 | 返回 `ambiguous` + 候选列表 |
| B08 | 文本没变也判成功 | 值无变化直接 `no_effect` |
| B09 | 引用只靠路径 | 增加 AutomationId 校验 |
| B10 | 滚动多滚一次 | 最后一次检查后不再滚 |
| B11 | 同分选大控件 | 改为优先小控件 |

另外：`element_state` / `type_verified` 默认只返回 `value_length` + 首 200 字符（`full=true` 取全文），
包版本号改为 `1.4.1rc2` 与 tag 一致。

## 验证

- 回归：**838 项 / 0 失败 / 0 错误 / 3 跳过**（新增 16 项针对本轮审计）
- 新增测试覆盖：动作失败上报、`SetValue` 走对方法、只读拒绝、结构字段保留、混合 TTL、
  `wait_for(any)` 分发层、`clear_first` 只输入一次、`absent` 不假成功、同名歧义、
  无 hwnd 补前台、值未变判 no_effect、AutomationId 变化判 stale、长文本摘要
