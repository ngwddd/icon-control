# Icon Control v1.4.0-rc1

发布候选。**功能已完成并通过本地验证，正式版等真机验收签收。**

## 这一版是什么

授权体系被换掉了：不再有"刚刚有没有人点过授权"这道门，改为**本地执行策略**——工具能不能动，
取决于"调用是否来自本机已连接的 MCP 会话"加上执行保护（急停、人机接管、目标窗口校验）。

- 默认不再启动授权桥、托盘、热键、授权窗口；
- 90 个工具、接口、schema 全部不变；
- 升级和重启都不需要重新授权；
- 需要旧的人工授权流程时：设 `ICON_CONTROL_POLICY=human`，行为与 1.3.9 完全一致。

## 升级

```powershell
# 安装 1.4.0rc1 的 wheel 后
python -m computer_mcp.launcher check   # 应显示 version 1.4.0rc1, source local
```

重启 MCP 连接即可生效。旧版的人工授权组件仍在包里，但默认不启动。
