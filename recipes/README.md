# 应用配方库（recipes）

每个文件 = 一个应用「怎么打开、怎么点、怎么验证、哪里有坑」。
新任务先看这里，不要重新探路。

| 文件 | 应用 | 关键点 |
|---|---|---|
| `app-01.json` | 某即时通讯软件 4.x（***） | UIA 不可用；回车发送；右下角锚点 |
| `app-02.json` | 某即时通讯客户端（***） | 双击开聊天窗；窗口常隐藏，重跑 exe 唤出 |
| `app-05.json` | 游戏平台（***） | app-05://openurl 开工坊；悬停卡片订阅 |
| `app-06.json` | 安全软件（***） 6.0 | 左侧图标栏坐标；信任区加白名单 |
| `系统文本编辑器.json` | 系统文本编辑器 | 最可靠的输入靶子（附两个陷阱） |

约定：
- `window` = 用来定位主窗口的过滤条件
- `flows` = 已验证的动作序列（可翻译成 macro 步骤）
- `pitfalls` = 用血换来的坑，先读再动手

> recipes 与 macros 中的软件名已用 `***` 占位（只保留软件性质）。使用时请替换成你自己环境里的真实名称。
